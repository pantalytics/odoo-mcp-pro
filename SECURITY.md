# Security policy

## Reporting a vulnerability

Mail rutger@pantalytics.com. Do not open a public issue for a security
problem.

What helps: the commit you tested, where in the code the problem sits, how
you reproduced it, and what you think the impact is.

We confirm receipt, fix before we disclose, and credit the reporter in the changelog and release notes unless they prefer
not to be named.

## Scope

- This repository (the open source server) at the latest release.
- The hosted service at mcp.pantalytics.com only with written permission and
  a test workspace we hand you. Ask first.
